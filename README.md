# Smart Leads Dashboard

A full-stack lead management dashboard scaffolded from the provided architecture notes.

## Setup

### Backend

cd backend
npm install
cp .env.example .env
# update .env values
npm run dev

### Frontend

cd frontend
npm install
cp .env.example .env
npm run dev

## Notes

- Backend runs on https://smart-leads-dashboard-s4gw.onrender.com
- Frontend runs on https://smart-leads-dashboard-livid.vercel.app
