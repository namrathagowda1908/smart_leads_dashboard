# Smart Leads Dashboard

A full-stack lead management dashboard scaffolded from the provided architecture notes.

## Setup

### Backend

cd backend
npm install
cp .env.example .env
# update .env values
npm run dev

### Frontend

cd frontend
npm install
cp .env.example .env
npm run dev

## Notes

- Backend runs on http://localhost:5000
- Frontend runs on http://localhost:5173
- API base URL is configured in rontend/.env.example
